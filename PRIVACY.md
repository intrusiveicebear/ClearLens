# ClearLens Privacy Summary

ClearLens analyzes photos locally on the Android device. The app does not request internet access and does not upload photos, thumbnails, hashes, filenames, scan results, or usage data. It has no account system, advertising SDK, or analytics SDK.

Photo access is used only to read gallery metadata and image thumbnails/content for analysis requested by the user. ClearLens cannot silently remove media: selected items are passed to Android's system-managed trash confirmation, where the user must approve the operation.

This project is a development build and this summary is not a substitute for the final store privacy policy and Data Safety declaration needed before public distribution.
